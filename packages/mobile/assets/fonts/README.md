# Home menu typography

`Kalam-Bold.ttf` and `Kalam-Regular.ttf` are Kalam by Indian Type Foundry,
distributed under the SIL Open Font License 1.1. The complete copyright and
license notice is retained in `Kalam-OFL.txt` beside the font files.

Sources:

- https://github.com/google/fonts/tree/main/ofl/kalam
- https://raw.githubusercontent.com/google/fonts/main/ofl/kalam/Kalam-Bold.ttf
- https://raw.githubusercontent.com/google/fonts/main/ofl/kalam/Kalam-Regular.ttf
- https://raw.githubusercontent.com/google/fonts/main/ofl/kalam/OFL.txt

These fonts are bundled locally and loaded through the existing Expo font module.
They are used for editable menu text, not rasterized labels. The menu still renders
with system handwriting fonts if font loading fails.
